# FairAI Analyzer: Bias Detection & Fairness Analysis Platform
**Project Report & Technical Documentation**

---

## 1. Project Overview
**FairAI Analyzer** is a production-style, web-based platform built to automatically detect, measure, and mitigate demographic biases in historical datasets. It is designed specifically for automated decision-making systems such as **CV/Resume Screening** and **College Admissions**. 

**Live Prototype:** [https://fairai-analyzer.run.app/prototype](https://fairai-analyzer.run.app/prototype)

Machine Learning models often inherit and amplify human biases present in training data. FairAI Analyzer provides data scientists and HR professionals with a transparent tool to evaluate their data *before* training a model, ensuring that automated decisions are fair, ethical, and legally compliant.

---

## 2. Core Features & Capabilities

* **Automated Bias Detection Engine:** Reads historical CSV datasets and calculates the selection rate for different demographic groups (e.g., Gender, College Tier, Geographic Location).
* **Fairness Scoring System:** Mathematically calculates a "Fairness Score" using the formula: `(Minimum Group Selection Rate / Maximum Group Selection Rate) * 100`. 
  * `90% - 100%`: Fair ✅
  * `60% - 89%`: Moderate Bias ⚠️
  * `< 60%`: Highly Biased ❌
* **Interactive Data Visualization:** Dynamically generates bar charts and volume graphs comparing the selection rates and total applicant volumes across demographic groups.
* **Smart Suggestion Engine:** Automatically generates actionable insights and recommendations based on the calculated severity of the bias.
* **"Before vs After" Simulation:** Synthetically rebalances the selection rates across groups to simulate what the dataset would look like if fairness constraints were applied, providing a direct visual comparison.
* **PDF Report Generation:** Allows users to download a comprehensive, formatted PDF report of the dashboard metrics and graphs in a single click for stakeholder presentations.

## 3. Detailed Technology Stack

The project uses a lightweight, robust, and highly modular technology stack split between a Python-based analytical backend and a dynamic web frontend.

### A. Backend Technologies
* **Python 3:** The primary programming language used for the backend logic due to its unparalleled ecosystem for data science and machine learning.
* **Flask:** A lightweight micro web-framework used to handle the HTTP routing, server requests, and session management. It connects the user's uploaded CSV file to the Python analysis engine and renders the resulting HTML templates.
* **Werkzeug:** A comprehensive WSGI web application library (used alongside Flask) that provides robust utilities, specifically used here for `secure_filename` to safely handle user file uploads and prevent path traversal attacks.

### B. Data Processing & Analytics Engine
* **Pandas:** The core data manipulation library. It is used to load the uploaded CSV datasets into DataFrames, validate required columns, group data by demographic attributes, and calculate aggregated selection metrics.
* **NumPy:** Used in tandem with Pandas to handle missing data (NaN values) and perform fast, vectorized mathematical calculations required for determining the fairness scores.

### C. Frontend Technologies (User Interface)
* **HTML5 & CSS3:** Used to structure and style the application. The UI utilizes modern design trends like **Glassmorphism** (frosted glass effects using CSS `backdrop-filter`) and CSS variables to implement a sleek **Dark Mode** toggle.
* **Vanilla JavaScript (ES6):** Handles client-side interactivity such as the dark mode toggle state, file upload displays, dynamic requirement list toggling, and triggering the PDF generation.
* **Jinja2:** The templating engine bundled with Flask. It is used to inject the server-side analytical results (variables, loops, and conditional statements) directly into the HTML to render the dynamic Results Dashboard.

### D. External Libraries & APIs
* **Chart.js:** A powerful, JavaScript-based data visualization library. It reads the JSON-parsed analytics data generated by the Python backend and renders the responsive, interactive bar and doughnut charts on the canvas.
* **html2pdf.js:** A client-side library that converts the HTML DOM elements (including the rendered Chart.js canvases) directly into a downloadable PDF format, entirely within the user's browser without requiring complex backend PDF generation dependencies.
* **FontAwesome:** Used for scalable vector icons throughout the UI to enhance the visual appeal of the dashboard and navigation elements.

---

## 4. Application Flow

1. **Upload Phase:** The user lands on the Home Page and navigates to the Upload section. They select the type of analysis (CV or Admission) and upload a CSV file.
2. **Validation Phase:** The Flask backend verifies the file extension and ensures the CSV contains the strictly required columns.
3. **Analysis Phase:** Pandas calculates the selection rates and the Bias Detection Engine generates the Fairness Score and smart suggestions. It also processes the mathematical simulation for the "After Mitigation" scenario.
4. **Reporting Phase:** The data is serialized to JSON and passed to the frontend via Jinja2 templates, where Chart.js visually renders the findings on the Results Dashboard.
